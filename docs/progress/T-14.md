# Task T-14 Progress Report: Frontend Core Pages (Ask, Case Viewer, History, Feedback)

## 1. Task Summary
- **Task ID:** T-14
- **Objective:** Implement core frontend user interface in React + Tailwind CSS with full support for Citation-Verified Legal Q&A, Case Viewer with paragraph anchoring/highlighting, Local Query History, User Feedback Capture, and Accessibility (`@a11y`).
- **Prerequisites:** T-11 (QA Orchestrator), T-12 (Citation Verifier), T-13 (Auth & Roles).

---

## 2. Key Components Implemented
1. **Frontend Architecture & Navigation:**
   - `frontend/src/App.tsx`: Tab-based stateful coordinator supporting `ask`, `search`, `case`, and `history` navigation.
   - `frontend/src/components/Header.tsx`: Semantic brand header (`<h1>LegalJarvis</h1>`), responsive navigation bar, and RBAC role badge.
   - `frontend/src/components/LegalDisclaimer.tsx`: Persistent, prominent informational research notice warning users against treating outputs as legal advice (FR-14 / FR-17).
   - `frontend/src/components/TransitionNotice.tsx`: Real-time Indian Criminal Law transition warning banner explaining the replacement of IPC, CrPC, and Evidence Act by BNS, BNSS, and BSA on 1 July 2024.
   - `frontend/src/components/FeedbackWidget.tsx`: Thumbs-up/down rating, classification labels (`supported`, `unsupported`, `hallucinated`, `incomplete`, `wrong_law`), and critique notes input.
2. **Core Pages:**
   - `frontend/src/pages/Ask.tsx`: Complete state lifecycle handling:
     - **Empty state:** Welcoming interface with sample Indian legal queries.
     - **Loading state:** Accessible progress indicator (`role="status"`, `aria-live="polite"`).
     - **Abstain state:** Prominent warning box when confidence/citations fall below threshold (`role="alert"`).
     - **Error state:** Accessible error banner with retry query button.
     - **Success state:** Formatted answer with inline clickable `[C1]`, `[C2]` citation pills that jump to the Case Viewer.
   - `frontend/src/pages/CaseViewer.tsx`:
     - Judgment reader with paragraph numbering (`¶ 1`, `¶ 2`...) and rhetorical segment badges (`Facts`, `Issues`, `Arguments`, `Reasoning`, `Holding`).
     - Auto-scroll & high-contrast amber ring/background highlighting on the target cited paragraph.
     - Sidebar with metadata (Court, Date, Neutral Citation, Bench) and dataset attribution (OGD / CC-BY 4.0).
   - `frontend/src/pages/History.tsx`:
     - Local storage query history tracking past inquiries, answers, timestamps, and citation counts.
     - Re-Ask button transferring queries directly back to the Ask page.
   - `frontend/src/pages/Search.tsx`:
     - Hybrid, dense, and lexical precedent search with instant navigation to Case Viewer paragraphs.
3. **Backend Support:**
   - `backend/app/api/documents.py`: `GET /v1/documents/{id}` and `GET /v1/documents` for the Case Viewer.
   - `backend/app/api/feedback.py`: `POST /v1/feedback` recording user ratings and diagnostic labels.
