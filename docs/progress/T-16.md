## 1. Overview & PRD Alignment

Task T-16 implements **FR-09 (Structured Summarisation)** per PRD Part F and Block 1 instructions:
- **Five Standard Rhetorical Role Sections:**
  1. `facts`: Factual background, FIR, trial history.
  2. `issues`: Questions of law / issues framed.
  3. `arguments`: Contentions of appellant / respondent / state.
  4. `reasoning`: Legal analysis, precedent discussion, statutory interpretation.
  5. `holding`: Final decision, disposition, bail orders, directions.
- **Rhetorical Role Segmenter (`RhetoricalSegmenter`):**
  - Evaluates rhetorical classification against IL-TUR RR / IN-Abs style rhetorical labels.
  - Implements multi-class F1 metric measurement (`evaluate_segmenter_f1`).
- **Structured Summarizer (`StructuredSummarizer`):**
  - Generates structured summaries with mandatory per-sentence `[P<no>]` paragraph citations.
  - Verifies claim-passage lexical overlap for every generated/extracted sentence using Jaccard/overlap thresholds from `compute_claim_passage_overlap`.
  - Offline fallback: Deterministic extractive summary organized into rhetorical sections when LLM API keys are unconfigured or unavailable.
- **REST Endpoints:**
  - `POST /v1/summarize`: Ad-hoc structured summary given a list of passages or text blocks.
  - `GET /v1/documents/{document_id}/summary`: Generates/retrieves structured summary for any ingested judgment.
