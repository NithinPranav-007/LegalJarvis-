## 1. Description & Scope
Implemented the Question Answering orchestrator connecting hybrid retrieval, prompt formulation, LLM inference, and citation resolution:
1. **Query Analysis (`backend/app/qa/query_analysis.py`)**:
   - Detects statutory provisions, section numbers, and year constraints.
   - Detects references to pre-2024 criminal statutes (IPC, CrPC, Indian Evidence Act) and automatically attaches the statutory transitional notice regarding the Bharatiya Nyaya Sanhita (BNS), Bharatiya Nagarik Suraksha Sanhita (BNSS), and Bharatiya Sakshya Adhiniyam (BSA) coming into force on 1 July 2024 per PRD FR-13.
2. **Context Assembly (`backend/app/qa/context_builder.py`)**:
   - Assembles top-ranked passages into numbered marker blocks (`[C1]`, `[C2]`, ...) with metadata headers (Title, Court, Neutral Citation, Paragraph Number).
   - Enforces configurable context token budgeting (~12,000 characters).
3. **Prompt Engineering (`prompts/qa_v1.txt`)**:
   - Strict grounding rules: answer solely from context passages; mandatory inline citation `[C1]` per factual sentence; explicit low-evidence abstention token `[INSUFFICIENT_EVIDENCE]`.
4. **QA Orchestration (`backend/app/qa/orchestrator.py`)**:
   - Combines query analysis, hybrid retrieval with reranking, context assembly, and LLM inference.
   - Post-processes answers to extract citation markers and map them to database `Chunk` records.
   - Supports graceful degradation: when LLM credentials are absent or fail, returns retrieved source passages with an explicit `generation_unavailable` notice.
5. **API & Schemas (`backend/app/schemas/qa.py`, `backend/app/api/qa.py`, `backend/app/main.py`)**:
   - `POST /v1/qa` endpoint accepting `QARequest` and returning `QAResponse`.
6. **Execution Verification (`scripts/eval_5_questions.py`)**:
   - Executed 5 real legal questions covering diverse Indian law domains and out-of-corpus abstention.
