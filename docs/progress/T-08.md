## 1. Description & Scope
Implemented dense semantic embedding, Reciprocal Rank Fusion (RRF), cross-encoder reranking, and unified hybrid search:
1. **Architectural Decision Recorded (`docs/decisions/0003-embedding-and-reranker-selection.md`)**:
   - Primary dense embedding model: `BAAI/bge-m3` (1024 dimensions, MIT license, revision `main`).
   - Primary cross-encoder reranker: `BAAI/bge-reranker-base` (MIT license, revision `main`).
   - Recorded licenses, dimension invariants, parameter scale, and offline fallback strategy.
2. **Embedding Pipeline (`backend/app/ingest/embed.py`)**:
   - `BaseEmbedder` abstract protocol.
   - `SentenceTransformerEmbedder` for GPU/CPU inference with `BAAI/bge-m3`.
   - `DeterministicHashEmbedder` producing normalized 1024-dimensional float unit vectors for rapid deterministic testing and air-gapped execution.
   - Batch chunk embedder (`embed_unindexed_chunks`) and CLI integration (`ljarvis embed --batch-size 64`).
3. **Dense Vector Retrieval (`backend/app/retrieval/dense.py`)**:
   - pgvector cosine distance retrieval on PostgreSQL.
   - Cosine similarity vector search fallback on SQLite.
4. **Reciprocal Rank Fusion (`backend/app/retrieval/fusion.py`)**:
   - Standard RRF implementation with smoothing constant $k = 60$ per Cormack et al. (2009) and PRD Section D3 / Part F.
   - Preserves 6-decimal score precision for distinguishing rank differences.
5. **Cross-Encoder Reranking (`backend/app/retrieval/rerank.py`)**:
   - `BaseReranker` interface with `CrossEncoderReranker` (`BAAI/bge-reranker-base`) and `LexicalBoostReranker` fallback.
6. **Unified Hybrid Orchestrator (`backend/app/retrieval/hybrid.py`)**:
   - Combines lexical hits and dense vector hits via RRF, followed by optional reranking.
   - API integration into `POST /v1/search` supporting `mode: "hybrid" | "lexical" | "dense"` and `rerank: bool`.
