## 1. Overview & PRD Alignment

Task T-17 implements **FR-08 (Upload and Analyse User Documents)**, **T-FR08**, and **NFR-PRIV (Privacy & Isolation)** per PRD Part F and Block 1 instructions:
- **Private Namespace & Multi-Tenant Isolation:**
  - Added `owner_user_id` to `documents` table and `chunks` table with indexed lookup.
  - In retrieval queries (`search_lexical_db`, `search_dense`, `search_hybrid`), queries filter strictly by `owner_user_id IS NULL OR owner_user_id = :uid`. Anonymous users receive only public corpus judgments.
  - In `GET /v1/documents/{document_id}`, if the document belongs to a specific user, unauthorized users receive `404 Not Found` (preventing document ID enumeration).
- **Postgres Row-Level Security (RLS) Layer:**
  - Implemented `backend/app/db/rls.py` providing official DDL statements:
    - `ALTER TABLE documents ENABLE ROW LEVEL SECURITY;`
    - `ALTER TABLE chunks ENABLE ROW LEVEL SECURITY;`
    - `CREATE POLICY documents_isolation_policy ON documents FOR ALL USING (owner_user_id IS NULL OR owner_user_id = NULLIF(current_setting('app.current_user_id', true), '')::bigint);`
    - `CREATE POLICY chunks_isolation_policy ON chunks FOR ALL USING (owner_user_id IS NULL OR owner_user_id = NULLIF(current_setting('app.current_user_id', true), '')::bigint);`
- **File Upload & Validation:**
  - `POST /v1/documents/upload`: Supports `.pdf` (via `pdfplumber`), `.docx` (via `docx`), `.txt`.
  - Max upload size: 20 MB (HTTP 413 on exceed).
  - Unsupported extension: HTTP 415.
  - Empty or unscannable text: HTTP 422.
  - Segmented with paragraph offsets via `segment_document`.
- **Log Sanitation Rule:**
  - Zero document text is leaked to logs. Log records contain only operational metadata (`user_id`, `doc_id`, `sha256`, `chunks`, `size_bytes`).
- **Retention Purge Job:**
  - `backend/app/jobs/retention.py`: `purge_expired_documents(db)` removes disk files, chunk embeddings, chunk records, and document metadata for user uploads whose `expires_at <= now` (default 30-day retention).
- **Deletion Endpoint:**
  - `DELETE /v1/documents/{document_id}` removes files on disk, chunks, embeddings, and database records.
