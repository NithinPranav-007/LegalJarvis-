## Extraction & Normalisation Pipeline
1. **Native Text Extraction**: Page-by-page extraction using `pdfplumber` tracking exact start and end character offsets (`page_offsets`).
2. **Unicode Normalisation & Dehyphenation**:
   - NFKC normalization.
   - Smart quotes, typographic dashes, and whitespace normalization.
   - De-hyphenation rejoining words split across line breaks (`juris-\ndiction` -> `jurisdiction`).
3. **Boilerplate Filtering**: Strips recurrent eSCR headers (`[2023] 16 S.C.R.`, `SUPREME COURT REPORTS`) and standalone page numbers.
4. **Language Classification**: Rejects non-English judgments (status: `skipped_lang`).
5. **Quality Scoring**: Evaluates alphabetic density, printable ratio, and dictionary token validity (0.0 to 1.0). Documents scoring >= 0.50 are marked `ok`.
