## Ingestion Architecture & Pipeline
1. **Size Gate Verification**: Checks target archive Content-Length against `MAX_DOWNLOAD_GB` (default 5.0 GB) before downloading.
2. **URL Scheme Validation**: Explicit validation enforcing HTTPS/HTTP endpoints before network operations (Bandit B310 compliant).
3. **SHA-256 Manifest Generation & Verification**: High-throughput chunked SHA-256 calculation for every downloaded PDF and metadata file.
4. **Tar Integrity & Unpacking**: Unpacks archives safely using `filter="data"` (Python 3.12+ safe).
5. **Metadata Matching**: Correlates filename base ID (`2023_16_872_887`) with `metadata.parquet` records (extracting title, decision date, neutral citation, CNR, and coram).
6. **Registration & Idempotency (T-FR01)**:
   - Registers `DatasetSnapshot`, `IngestionRun`, and `Document` records.
   - Enforces unique constraint on `(court_id, external_id)`.
   - On repeat execution, already-registered documents are safely skipped and reported, adding 0 new rows.
