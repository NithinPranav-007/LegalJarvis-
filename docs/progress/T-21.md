## 2. Implemented Components

### A. Container Orchestration (`docker-compose.yml`)
- **`db` Service:** PostgreSQL 16 with `pgvector/pgvector:pg16`, healthcheck, isolated volume `pgdata`.
- **`backend` Service:** Multi-stage Python 3.11-slim container with tesseract OCR, wait-for-db healthcheck dependency, hot-reloading uvicorn server.
- **`frontend` Service:** Node 20-alpine container running Vite client on port 5173.

### B. Deployment Smoke Test Suite (`scripts/ops/smoke_harness.py`, `smoke.ps1`, `smoke.sh`)

### C. Database Backup and Restore Automation (`db_backup_restore.py`, `backup.ps1`, `restore.ps1`)
- Supports running PostgreSQL container via `docker compose exec -T db pg_dump` and fallback local SQLAlchemy database snapshot dumps.
- Generates SHA-256 integrity manifest (`.sha256`) alongside SQL dump file.
- Restore verifies SHA-256 checksum before applying database restoration.
- Added `backups/` to `.gitignore` to prevent committing SQL dumps per Rule 10.
